# Screenshots

This directory contains project screenshots for the README deliverables.

## Required Screenshots

1. **mobile-responsive.png** — Mobile responsive UI showing the app on a phone screen (< 768px)
2. **cicd-pipeline.png** — GitHub Actions CI/CD pipeline running with all jobs passing
3. **test-output.png** — Terminal showing `npm test` output with 119 passing tests
4. **contract-deployment.png** — Contract deployment script output showing contract IDs

## How to Capture

```bash
# Mobile responsive: Use Chrome DevTools device toolbar (iPhone 14 Pro)
# CI/CD: Screenshot the Actions tab after a successful run
# Test output: Run `npm test` and take a terminal screenshot
# Contract deployment: Run `npm run contracts:deploy` and capture output
```

Images should be PNG format, optimized with `pngquant` or similar.
